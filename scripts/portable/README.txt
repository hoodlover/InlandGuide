INLAND GUIDE — PORTABLE WINDOWS VERSION

1. Copy Inland-Guide-Portable.zip from Z:\Rail Tools by Lance\Inland Guide Lookup Tool to your Desktop or Documents.
2. Right-click the ZIP, choose Extract All, and finish extracting it.
3. Open the extracted Inland Guide folder and double-click Open Inland Guide.vbs.
4. The guide opens in your default browser. You can make a desktop shortcut to the VBS file.

No installation, admin access, or separate Node.js installation is needed.
Keep the app folder and launcher together. Do not run the launcher inside the ZIP.

MASTER DATA
The launcher automatically reads your OneDrive-synced InlandCutoffGuide.xlsm.
If it is not synced, the guide shows a button to the Inland SharePoint folder
and instructions to Sync it. Sign in to OneDrive with your work account.
For offline use, right-click the synced workbook and choose Always keep on this device.
No file picker is required, and the guide does not change the workbook or run its macros.

Every launch/refresh checks the master. An open guide checks every minute and
when you return to its window, and offers a refresh when the workbook changes.
SharePoint edits become available after OneDrive finishes syncing them.
If the master becomes unavailable, refresh/reopen once syncing is complete.

Other reference information (including CPKC schedules and display names) is
included with this package and changes when you receive a replacement ZIP.
Online manager publishing, usage statistics, and requests are unavailable locally.
Workplace links and live external services still need a network connection.
The local launcher stops after 30 minutes without browser requests.

For a newer app version, close the guide, extract the new ZIP to a new folder,
and launch it. The new folder's launcher replaces the old local launcher.
Contact Lance Cobb if you need help.
